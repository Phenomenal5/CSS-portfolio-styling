# 🌟 Styled Portfolio Project

This project is a continuation of the basic portfolio created in the previous checkpoint. In this stage, I focused on styling the portfolio using CSS to make it more visually appealing and polished.

## 📄 What I Did

- Sectioned the index page into different segment.
- Created a `styles.css` file
- Linked the CSS file to the all the HTML documents
- Styled the navigation bar to display inline
- Changed the font to **Roboto**
- Added class attributes to HTML elements for targeted styling
- Made creative design choices to personalize the layout and theme

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts (Roboto)

## 🎨 Design Approach

The goal was to create a clean and modern-looking portfolio. I used semantic HTML for structure and applied custom CSS for layout, colors, and typography. Creativity was encouraged, so I tried to make the design unique and expressive.
